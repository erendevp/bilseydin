TikTok bağlantısı

Kodun hazır. Kopyala, GitHub'da Actions → "TikTok hesabını bağla (bir kez)" → Run workflow kutusuna yapıştır.

Kod birkaç dakika içinde geçerliliğini yitirir, hemen kullan.

Bu sayfa TikTok'un yönlendirme adresidir. Bağlantıyı başlatmak için kurulum rehberindeki TikTok yetki bağlantısını aç.
